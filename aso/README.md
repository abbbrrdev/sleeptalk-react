# SleepTalk — App Store (ASO)

Всё для страницы в App Store на 11 языках: тексты в файлах `<локаль>.md`, скриншоты — в `screenshots/<локаль>/`, исходник — `metadata.json`.

## Общие поля (вкладка «Информация о приложении»)
- **Категория:** основная — Здоровье и фитнес (Health & Fitness), дополнительная — Развлечения (Entertainment).
- **Основной язык:** English (U.S.). Остальные 10 языков добавь через выпадающий список языков справа сверху.
- **Права на контент:** «Нет, не содержит контента сторонних разработчиков».
- **Возрастной рейтинг:** во всех пунктах опросника «Нет» → 4+.
- **Авторские права:** `© 2026 Broni` (или имя, на которое оформлен аккаунт).
- **URL службы поддержки / Маркетинг (URL):** адрес задеплоенного сайта (`site/`).
- **Политика конфиденциальности:** `<адрес сайта>/privacy`. Во всех описаниях вместо `{{PRIVACY_URL}}` подставь этот же адрес.
- В App Review Notes: «Background audio records sleep sounds overnight at the user's request; the recording indicator stays visible. Only short clips are kept, on device.»

## Скриншоты
- 5 штук на язык, **1284 × 2778 px** — загружай в слот «iPhone 6,5-дюймовый дисплей». Порядок важен: первые 2–3 видны в поиске.
- Приложение только для iPhone (`supportsTablet: false`), iPad-скриншоты не нужны.
- Тексты на скриншотах совпадают с разделом «Подписи на скриншотах» в каждом `.md`.

## Видео (App Preview)
- `previews/<локаль>/preview.mp4`: 886 × 1920, 30 fps, H.264 High, до 12 Мбит/с, AAC stereo, 25–29 секунд. Подходит для слотов 6,5″ и 6,9″.
- Загружай в тот же язык, что и скриншоты: страница версии → «Предварительный просмотр приложения» → перетащи файл. Видео ставится перед скриншотами и в поиске проигрывается автоматически, без звука.
- Обложку (Poster Frame) Apple по умолчанию берёт с 5-й секунды — там первый экран с заголовком. При желании её можно выбрать при загрузке.
- В роликах только реальные экраны приложения, без рук и устройств — это требование Apple.

## Правила, по которым писались ключевые слова
- До 100 символов, через запятую без пробелов, без слов, которые уже есть в названии/подзаголовке (Apple и так их индексирует).
- Без названий конкурентов и чужих брендов — за это отклоняют.
- В каждой стране — свои поисковые слова, а не перевод английских.
